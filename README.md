# portfolio

榎本大貴（株式会社LITALICO 執行役員／LITALICO研究所 所長／AI統括部長、任意団体「みんなのアクセス」代表）の個人ポートフォリオサイトです。

公開URL: https://enochan.github.io/portfolio/

## 構成

ビルド不要の静的サイトです。

| ファイル | 内容 |
| --- | --- |
| `index.html` | サイト本体（HTML・CSS・JavaScript をすべて含む単一ファイル） |
| `events.json` | タイムラインに追加する項目（予定を含む）のデータ。ページが読み込み時に取得して表示します |
| `favicon.ico` / `apple-touch-icon.png` | ファビコン（ブラウザのタブ用、16・32・48px）と、スマホのホーム画面用アイコン（180px）。どちらも「みんなのアクセス」のロゴの Q! のマーク（文字なし）から作成 |
| `.nojekyll` | GitHub Pages で Jekyll の処理を無効にするための空ファイル |
| `llms.txt` | AI エージェント向けの案内（[llmstxt.org](https://llmstxt.org/) の形式）。人物の要約、主な活動、連絡方法、リンクを Markdown で書いています。公開URLは https://enochan.github.io/portfolio/llms.txt |

`index.html` のプロフィールやリンクを変えたときは、`llms.txt` も同じ内容に合わせて更新してください。

フォントは Google Fonts の「Zen Maru Gothic」を読み込んでいます。

## ローカルでの確認方法

`events.json` はページから `fetch` で読み込むため、`index.html` をブラウザで直接開く（`file://`）と、`events.json` の項目は表示されません（それ以外は表示されます）。すべて確認するときは、リポジトリ直下で簡易サーバーを起動します。

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開いてください。

## 更新の仕方

1. `index.html` を編集します。タイムラインへの項目（予定を含む）の追加は `events.json` を編集します（次の「タイムラインに項目を追加する」を参照）。
2. ブラウザで表示を確認します。PC 幅とスマホ幅（390px 前後）の両方で、横スクロールが出ないこと、キーボード操作（Tab キー）でフォーカス位置が見えることも確かめてください。
3. `main` ブランチにコミット・プッシュすると、数分で公開サイトに反映されます。

## タイムラインに項目を追加する（予定を含む）

リポジトリ直下の `events.json` に 1 件ずつ追加します。`index.html` を触る必要はありません。

### 手順

1. `events.json` を開きます。ファイル全体が 1 つの配列（`[` と `]`）で、その中に 1 件ずつ `{ … }` が並んでいます。
2. 配列の中に 1 件を追加します。1 件は 1 行で書き、前の項目の行末にカンマ（`,`）を付けます。最後の項目の後ろにはカンマを付けません。並び順は自由です（表示時に日付順に並べ替えます）。
3. `main` ブランチにコミット・プッシュします。数分で公開サイトに反映されます。

### 書き方の例

```json
[
  {"date": "2026-11-27", "type": "talk", "label": "研修", "title": "福祉事業所のAI導入と活用セミナー", "detail": "神奈川県後援・障害福祉サービス事業所の方向け／ユニコムプラザさがみはら"},
  {"date": "2026-12-10", "type": "write", "label": "執筆", "media": "note", "title": "記事タイトル", "url": "https://note.com/enomotod/n/xxxxxxxx"}
]
```

（2 件目は書き方の例です。実際の `events.json` には入っていません。）

必要なキーだけを書きます。任意のキーは、使わないときは書かずに省略します。

| キー | 必須 | 内容 |
| --- | --- | --- |
| `date` | 必須 | 日付。`YYYY-MM-DD` 形式（例：`2026-12-05`） |
| `type` | 必須 | 種類。`talk`（登壇・講座）、`write`（執筆・インタビュー）、`career`（経歴）のいずれか。絞り込みボタンはこの値で表示を切り替えます |
| `label` | 必須 | カードのバッジに出す文字（例：`登壇`、`講義`、`研修`、`ウェビナー`、`執筆`、`インタビュー`、`経歴`） |
| `title` | 必須 | タイトル |
| `detail` | 任意 | タイトルの下に出す補足（イベント名・会場など） |
| `media` | 任意 | 日付の横に出す媒体名（例：`note`、`Zenn`） |
| `url` | 任意 | 指定するとタイトルがリンクになります |

追加した後は、JSON として正しいかを確かめてください（例：`python3 -m json.tool events.json`）。エラーが出なければ形式は正しく書けています。

### 表示のされ方

- 閲覧した日（閲覧者の端末の日付）より **後** の日付の項目は「予定」として扱い、タイムラインの一番上の「これから」にまとめて表示します。日付が近い順に並び、カードには「予定」のバッジが付き、日付は `2026.12.05` のように年から表示します。
- 閲覧した日と同じ日付、またはそれより前の日付の項目は、通常の過去の項目として、該当する年の中に日付順で表示します。その年の見出しがまだなければ自動で作られます。
- 日付が過ぎると、書き換えなしで自動的に「これから」から年の中へ移ります。
- 予定が 0 件のときは「これから」は表示されません。
- 絞り込みボタンと、スクリーンリーダー向けの件数の読み上げ（例：「登壇・講座：10件を表示しています（うち予定1件）」）にも反映されます。
- `events.json` を読み込めなかったとき（JSON の書き方の誤り、通信エラーなど）は、`events.json` の項目だけが表示されず、`index.html` に書かれた既存の項目は通常どおり表示されます。原因はブラウザのコンソールに出ます。日付やタイトルが欠けた項目は、その 1 件だけ表示されません。
- JavaScript が無効な環境では、`events.json` の項目は表示されません。
- ブラウザのキャッシュで古い内容が出ないよう、毎回サーバーに更新を確認して読み込みます。

既存の過去の項目は、これまでどおり HTML（`<div class="year">` の中の `<li data-type="…">`）に直接書かれています。HTML で書いた項目も、`<time datetime="YYYY-MM-DD">` が閲覧日より後の日付なら「これから」に移ります。

## お問い合わせフォーム

ページ下部の「お問い合わせ」フォームは、外部サービスの [FormSubmit](https://formsubmit.co/) を使って送信します。宛先のメールアドレスは HTML には書かず、FormSubmit が発行した伏せ字のエンドポイント（`https://formsubmit.co/ajax/…`）を使っています。

- 送信は JavaScript でページ遷移なしに行います。JavaScript が無効な環境では、フォームの通常の送信（POST）で FormSubmit に送られます。
- 件名（`_subject`）、メールの形式（`_template`）、CAPTCHA の無効化（`_captcha`）、スパム対策のハニーポット（`_honey`）は、フォーム内の hidden 項目で指定しています。
- 動作確認でテスト送信をすると、実際にメールが届きます。表示の確認だけなら、ブラウザの開発者ツールで `fetch` を差し替えるなどして送信を止めてください。
